# Crazy Menu — Geode project

A goofy Geometry Dash Geode mod for Windows / GD 2.2081.

## Keybind
Default: **Alt + Grave (`)**. You can change it in Geode's mod settings.

## Goofy settings
- Rainbow UI Chaos
- Among Us Mode
- Skill Issue Detector
- Brainrot Mode

The popup displays the enabled setting states and some unserious stats.

## Build
This is a Geode source project, not a compiled `.geode` package yet.
1. Install Geode SDK + Geode CLI for Geometry Dash.
2. Open this folder in a Geode-ready CMake environment.
3. Run `geode build` from this project folder.
4. The compiled `.geode` output will be in the build output folder.

SDK and CLI setup: https://docs.geode-sdk.org/
